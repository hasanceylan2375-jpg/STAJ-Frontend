Sıkça Sorulan SorularFrequently Asked Questions

Müşteri Yönetim Sistemi hakkında merak edilenlerThings you may wonder about the Customer Management System

Müşteri nasıl eklenir?How do I add a customer?

Sol menüde bulunan "Müşteri Ekle" bölümünden müşteri bilgilerini girerek kayıt oluşturabilirsiniz.You can create a record by entering customer information in the "Add Customer" section.

Müşterileri nereden görebilirim?Where can I view customers?

"Müşteri Listele" bölümünden sisteme kayıtlı müşterileri görüntüleyebilirsiniz.You can view registered customers in the "Customer List" section.

Müşteri bilgileri güncellenebilir mi?Can customer information be updated?

Evet. Müşteri listesindeki güncelleme işlemi üzerinden bilgileri değiştirebilirsiniz.Yes. You can change information using the update action in the customer list.

Müşteri silinebilir mi?Can a customer be deleted?

Evet. Müşteri listesindeki silme işlemi ile kayıt sistemden kaldırılabilir.Yes. The record can be removed using the delete action in the customer list.

Sistem güvenli mi?Is the system secure?

Uygulamada Guard, AuthService ve HTTP Interceptor kullanılarak temel kimlik doğrulama ve yetkilendirme yapısı oluşturulmuştur.The application uses Guard, AuthService and an HTTP Interceptor for basic authentication and authorization.
