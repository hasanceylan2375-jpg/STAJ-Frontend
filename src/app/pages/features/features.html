Sistem ÖzellikleriSystem Features

Müşteri Yönetim Sisteminin sunduğu özelliklerFeatures offered by the Customer Management System

👤 Müşteri EklemeAdd Customer

Yeni müşterileri sisteme kolayca ekleyebilirsiniz.You can easily add new customers to the system.

📋 Müşteri ListelemeCustomer Listing

Kayıtlı müşterileri tek bir ekrandan görüntüleyebilirsiniz.You can view registered customers on a single screen.

✏️ GüncellemeUpdate

Müşteri bilgilerini gerektiğinde güncelleyebilirsiniz.You can update customer information when needed.

🗑️ SilmeDelete

Artık ihtiyaç duyulmayan müşteri kayıtlarını silebilirsiniz.You can delete customer records that are no longer needed.

🔐 GüvenlikSecurity

Guard ve token tabanlı yetkilendirme altyapısı kullanılmaktadır.Guard and token-based authorization infrastructure is used.

⚡ Hızlı APIFast API

Angular ve REST API ile backend ile hızlı iletişim sağlanır.Fast communication with the backend is provided through Angular and REST API.

💳 Kredi Ödeme PlanıLoan Payment Plan

Kredi tutarı, vade, faiz, BSMV ve KKDF bilgilerine göre ödeme planı hesaplanabilir.A payment plan can be calculated based on loan amount, term, interest, BSMV and KKDF.

📊 Eşit Taksitli / Eşit Anaparalı HesaplamaEqual Installment / Equal Principal Calculation

Farklı ödeme tipleriyle taksit, anapara, faiz, vergi ve kalan borç detayları görüntülenebilir.Installment, principal, interest, tax and remaining balance details can be viewed with different payment types.

🏠 Konut Kredisi ÖrneğiHome Loan Example

120 ay vadeli konut kredisi için hazır örnek hesaplama kullanılabilir.A ready-made example calculation is available for a 120-month home loan.

🚗 Araç Kredisi ÖrneğiVehicle Loan Example

48 ay vadeli araç kredisi için hazır örnek hesaplama kullanılabilir.A ready-made example calculation is available for a 48-month vehicle loan.
