Müşteri Yönetim Sisteminin sunduğu özelliklerFeatures offered by the Customer Management System

👤 Müşteri EklemeAdd Customer

Yeni müşterileri sisteme kolayca ekleyebilirsiniz.You can easily add new customers to the system.

📋 Müşteri ListelemeCustomer Listing

Kayıtlı müşterileri tek bir ekrandan görüntüleyebilirsiniz.You can view registered customers on a single screen.

✏️ GüncellemeUpdate

Müşteri bilgilerini gerektiğinde güncelleyebilirsiniz.You can update customer information when needed.

🗑️ SilmeDelete

Artık ihtiyaç duyulmayan müşteri kayıtlarını silebilirsiniz.You can delete customer records that are no longer needed.

🔐 GüvenlikSecurity

Guard ve token tabanlı yetkilendirme altyapısı kullanılmaktadır.Guard and token-based authorization infrastructure is used.

⚡ Hızlı APIFast API

Angular ve REST API ile backend ile hızlı iletişim sağlanır.Fast communication with the backend is provided through Angular and REST API.
